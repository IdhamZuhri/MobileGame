# Roadmap

## Done
1. Core movement and procedural open world
2. Combat: auto-attack, biome enemies, XP gems, leveling, HUD
3. Progression: level-up upgrade choices, saving
4. Gear and inventory with rarities
5. Village hub, bosses, quests, gold, distance-scaled danger

## Next
6. PWA: installable, full-screen, offline; sound effects and music; particle effects

## Ideas
- More boss mechanics (charge, summon, phases) and mini-bosses
- Weapon types with different attack patterns (melee arc, piercing, area)
- Pets or companions
- Skill tree and prestige / new game plus
- Day and night cycle, weather
- More biomes (swamp, volcano) and dungeons with keys
- Gear sets, crafting and upgrading items
- Achievements and a daily quest
- Cloud save or export and import of the save file
- Real art and an animated character

## How updates ship
1. Work happens on a feature branch.
2. Each feature is tested in a headless browser, committed, pushed and opened as a pull request.
3. Merging into `main` redeploys the GitHub Pages site within 1-2 minutes.
4. Refresh the page (or open it in a private tab) to see the new version.
5. Saves persist across updates because loading merges over defaults.
